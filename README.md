## 🚀 Featured Projects

### 🔐 [MetaGuard](https://github.com/shubham4734singh) — *Privacy-First Metadata Analyzer*
> *"Your files tell a story. Decide what they say."*

A full-stack privacy-focused web app that helps users analyze and strip sensitive metadata from files before sharing.

**Features:** File upload (docs/images/media) → Metadata inspection → Privacy risk scoring → Clean with configurable policies → Secure auth + history dashboard

**Stack:** `Django REST` + `React (Vite + TypeScript)`

---

### 🔓 [Password Cracker Web App](https://github.com/shubham4734singh/Password_Recovery)
A modern browser-based tool for recovering numeric passwords (0–9) from encrypted PDF, ZIP, 7Z, TAR, and RAR files.

**Features:** Configurable digit lengths (1–8) · Real-time progress · Local processing · Auto file unlock + download · Clean responsive UI

---

### 🔍 Permission Analyzer *(In Progress)*
A tool to analyze and monitor system/app permissions, flagging sensitive access (camera, location, storage) with a user-friendly risk report. Lightweight and local — no data leaves your device.
